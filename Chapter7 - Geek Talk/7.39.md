# 高效复盘两套模型：KISS 和 GRAI

> 很多人对复盘有一个误区：复盘 = 追责、挑错、开会批人。
但真正高效的复盘，核心从来不是追究谁的责任，而是沉淀经验、定位问题、识别干系人，让干系人去跟进、推动、落地，更是拿到可落地的方案，避免重复踩坑，把单次的经验，变成长期可复用的能力。

## 一、两套复盘模型
复盘不是只有一套模板，根据场景选对工具，复盘才不会流于形式。这里分享两套最实用的复盘模型：GRAI模型 和 KISS模型，二者定位差异很大，选对了事半功倍。

### 1. GRAI 模型

「GRAI 模型」深挖根因，适合重大复盘。
定位：偏原因分析、深度诊断，适合重大故障、事故复盘、季度/半年度复盘、重大项目收尾复盘。
核心四步：Goal → Result → Analysis → Insight

- Goal 目标：先对齐当初的预期目标是什么，明确衡量标准。没有目标，结果好坏就没有评判依据

- Result 结果：对照目标，客观还原真实结果。目标和结果放在一起对照，差距才会清晰浮现

- Analysis 分析：拆解差距背后的原因，分两步走

  - 穷举：先放开思路，把所有可能相关的原因全部罗列，不提前定性、不急于下结论；

  - 深挖：借助5Why追问法，层层剥离表面现象，挖到根本原因，而不是停留在“表面诱因”

- Insight 洞察：分析的最终落脚点，不是罗列一堆原因，而是提炼出底层规律、认知升级。这是复盘最有价值的产出

适用场景：项目反复延期、线上故障、重大交付翻车、周期长、影响范围大的事项。这类问题表象之下藏着流程、协作、方案层面的深层问题，只调整动作治标不治本，需要GRAI做深度剖析。



### 2. KISS 模型

「KISS 模型」聚焦行动，适合日常轻复盘
定位：偏落地动作迭代，适合日复盘、周复盘、小迭代节点、常规项目阶段性小结。
四个维度：Keep → Improve → Stop → Start

- Keep 保留：哪些动作、做法、流程拿到了正向结果，沉淀固化，继续坚持。把偶然的成功，变成稳定、可复制的成功。
- Improve 改进：大方向没问题，但细节、节奏、方式有瑕疵，结果达标但达不到预期，找到优化点持续打磨。
- Stop 停止：哪些做法本身就是错的、低效的、负向消耗的，果断叫停；也包含优先级过低、投入产出比差的事项，及时止损。
- Start 开始：接下来要新增哪些动作、尝试什么新方法、启动哪些计划，补齐短板。



### 3. 核心思考

KISS的重心在行动。KISS 模型中什么重要？Keep 重要、Improve 重要，比较少的人可以从失败变成成功，所以把成功的事情变得恒成功相对容易，保持下去。距离成功不太远，或者虽然成功了，但不够超出预期，还可以持续优化。

但同一个项目，每个交付节点的产出都不满意，甚至经常延期，最后整个项目虽然上线了，但是项目的健康度不够，甚至还引发了一些故障。那 keep 什么？问题太多，KISS 模型不适用了，改用 GRAI 模型看看，要对原因进行复盘了，要对大方向进行复盘了。

另外 KISS 模型中，Stop 也很重要，哪些事情由于不对，所以不做了。或者说要调整优先级了。KISS 模型重心在结果，以结果为导向，复盘的确需要找原因，但是原因是需要在一个时间范围内才有效（或者在当前上下文、时间窗口内 ROI 更高），但如果是1天1次复盘，或者一周1次复盘，原因可能不是短周期内需要关注的事情，当下窗口内行动更为关键、结果更为重要。



## 二、怎么选模型？

一个判断标准
✅ 阶段性产出持续不满意、频繁延期、项目带病上线、引发故障、底层方向/流程有隐患 → 优先 GRAI
问题已经不是微调动作就能解决，必须对齐目标、还原差距、深挖根因、刷新认知。

✅ 常规迭代、每周小结、短期小任务、整体结果可控，只是想要持续优化效率和产出 → 优先 KISS
聚焦行动迭代，轻量化、高频做，持续微调，维持稳定产出。

补充边界：两套模型不是互斥的。一次完整复盘，可以先用KISS快速梳理动作清单，如果发现重大异常，再切入GRAI做专项深度拆解。



## 三、AI时代，复盘的增效玩法
不少团队其实一直在用类似思路复盘，只是不知道对应的模型名称，复盘文档零散、梳理耗时、容易遗漏视角。
现在可以把项目文档、聊天纪要、故障记录、交付日志等原始素材交给AI，明确指定使用KISS或者GRAI框架，让AI先帮你完成信息汇总、结构化梳理，快速产出初稿复盘文档。
注意：AI负责整理信息、搭建框架、补全视角，但根因判断、关键洞察、最终决策，依然需要人来把关。AI是复盘助手，不能替代人的判断。



## 四、一言以蔽之

- KISS 管日常迭代：管好手脚，稳定输出
- GRAI 管重大危机：理清逻辑，升级认知

复盘的目的，不是为了证明谁错了，而是让每一次经历，都变成下一次赢的筹码
